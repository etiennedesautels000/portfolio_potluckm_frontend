# Portfolio Projet : Potluck Manager - Frontend

Une application web qui gère les contributions des invités à un potluck.  
Visiter la page démo (voir lien plus bas)

### Fonctionnalités
- **Gérer les potlucks**:
  - lister, créer, modifier, supprimer un potluck
  - paramètres: date, heure, titre, organisateur, lieu
- **Gérer les contributions**:
  - lister, créer, modifier, supprimer une contribution
  - paramètres: nom, catégorie, notes
  - chaque contribution doit être associée à un sous-groupe (gérer sous-groupes)

### Stack technique
- Langage: **Javascript, HTML, CSS**
- Lien avec le service web (API) du même projet
